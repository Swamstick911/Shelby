01 — the idea

A console nobody was gaming on.

Sprig is by Hack Club. Raspberry Pi Pico, eight buttons, one little screen.

“Every player is a creator,” the box said. Fine — I created an operating system instead of a game.

The Sprig is genuinely lovely hardware: a dual-core RP2040, a crisp 160×128 LCD, two D-pads, and 30 hours on a pair of AAAs. It’s built to write little JavaScript games in a browser editor and flash them over USB. I did that for an afternoon, and then the device went in a drawer.

What I really wanted was something that earned a permanent spot on my desk — something glanceable. So Shelby keeps the hardware and throws out the premise. It boots straight into a clock, syncs the time over Wi‑Fi, and from one button-press you reach the handful of things I check all day: my GitHub contribution graph, my Hackatime hours, a task list, the device’s own vitals, and a little music player for good measure.

It’s written in MicroPython, lazy-loads each app so the 264 KB of RAM survives, and runs the chip a little hot at 250 MHz so the clock never stutters. None of that matters to you. What matters is it’s the most useful object on my desk that cost me zero dollars.

05 — make it yours

Four steps from stock to Shelby.

You’ll need a Sprig, a USB cable, and Python on your machine.

  1. Grab the firmware

    Clone the repo (or download a release) and install the upload tooling.

  2. Add your secrets

    Copy secret.py.example to secrets.py and drop in your Wi‑Fi, GitHub token, and Hackatime key.

  3. Set your tasks

    Open tasks.json and write the to-dos you want on the screen. That’s the whole task backend.

  4. Flash it over USB

    Plug the Sprig in and push everything with mpremote. It reboots straight into the clock.

# 1 — get it
git clone https://github.com/Swamstick911/Shelby
cd Shelby
pip install mpremote

# 2 — your secrets
cp secret.py.example secrets.py
# edit wifi / github token / hackatime key

# 3 — flash the whole tree
mpremote connect auto fs cp -r . :
mpremote reset

# → boots into Shelby. press L for the menu.
